### 周五: Maven核心概念(第5天)

**目标**: 理解pom.xml结构和Maven依赖管理
**预计用时**: 50-75分钟

#### 理论学习(20-25分钟)

**学习内容**:
1. pom.xml核心结构:
```xml
<project>
    <groupId>com.example</groupId>
    <artifactId>my-project</artifactId>
    <version>1.0-SNAPSHOT</version>

    <dependencies>
        <dependency>
            <groupId>junit</groupId>
            <artifactId>junit</artifactId>
            <version>4.13.2</version>
            <scope>test</scope>
        </dependency>
    </dependencies>
</project>
```

2. Maven坐标三要素:
   - groupId: 组织标识
   - artifactId: 项目标识
   - version: 版本号

3. 依赖传递性和依赖冲突解决
   - 排除依赖: <exclusions>
   - 依赖优先级: 声明优先、路径优先

**动手练习**:
```xml
<!-- 在pom.xml中添加常用依赖 -->
<dependencies>
    <!-- JUnit单元测试 -->
    <dependency>
        <groupId>junit</groupId>
        <artifactId>junit</artifactId>
        <version>4.13.2</version>
        <scope>test</scope>
    </dependency>

    <!-- MySQL驱动 -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <version>8.0.33</version>
    </dependency>

    <!-- Lombok -->
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <version>1.18.30</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```

### 周六上午: Maven命令实践(第6天上午)

**目标**: 掌握Maven核心命令和项目生命周期
**预计用时**: 1.5小时

#### 理论学习(30分钟)

**学习内容**:
1. Maven生命周期三大阶段:
   - clean: 清理项目(mvn clean)
   - default: 构建项目(mvn compile/test/package/install)
   - site: 生成项目文档

2. 核心命令详解:
```bash
mvn clean              # 清理target目录
mvn compile            # 编译src/main/java
mvn test               # 编译并运行测试
mvn package            # 打包(生成jar/war)
mvn install            # 安装到本地仓库
mvn clean package      # 组合命令: 清理+打包
mvn clean test         # 组合命令: 清理+测试
```

3. 常用插件配置:
```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.8.1</version>
            <configuration>
                <source>17</source>
                <target>17</target>
            </configuration>
        </plugin>
    </plugins>
</build>
```

---

#### 实践操作(1小时)

**练习任务**:
1. 打开IDEA终端(Terminal),进入项目目录
2. 依次执行以下命令,观察每次命令后的变化:
```bash
mvn clean              # 删除target目录
mvn compile            # 生成target/classes
mvn test               # 执行测试(无测试类会跳过)
mvn package            # 生成target/*.jar
mvn install            # 安装到本地仓库
```

3. 验证命令执行结果:
   - target目录是否存在
   - classes目录下是否有.class文件
   - jar包是否生成

**验收标准**:
- [ ] 掌握5个核心命令的用途
- [ ] 理解Maven生命周期
- [ ] 能独立使用命令构建项目

**目标**: 掌握Apifox基础使用和HTTP请求创建
**预计用时**: 1小时

#### 理论学习(25分钟)

**学习内容**:
1. Apifox是什么?
   - API文档、调试、Mock、测试一体化平台
   - 比Postman更适合国内使用
   - 支持团队协作

2. 核心概念:
   - 项目: 管理一组接口
   - 接口: 定义HTTP请求
   - 环境变量: 统一管理基础URL
   - Mock: 模拟接口响应

3. HTTP请求方法:
   - GET: 查询数据
   - POST: 新增数据
   - PUT: 更新数据
   - DELETE: 删除数据

**动手练习**:
1. 下载安装Apifox(https://www.apifox.cn/)
2. 注册/登录账号
3. 创建第一个项目"API测试"
4. 创建GET请求:
   - 方法: GET
   - URL: https://jsonplaceholder.typicode.com/posts/1
   - 点击发送,查看响应
